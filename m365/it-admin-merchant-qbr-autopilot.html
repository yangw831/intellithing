Where users find it

Users discover Merchant QBR AutoPilot from its Teams app listing, the Microsoft 365 Copilot app link, or Microsoft Marketplace. If tenant policy blocks self-service installation, they see a Request approval option instead of immediate access.

What it does

Merchant QBR AutoPilot is a Copilot agent that helps account managers and merchant success teams prepare Quarterly Business Review (QBR) scorecards directly inside Microsoft 365 Copilot and Teams. Users can generate one merchant scorecard or batch-generate scorecards from a CSV or TSV file in their OneDrive. The agent returns structured scorecards with executive summaries, recommended actions, PowerPoint outputs, optional ZIP bundles, and organized OneDrive workspaces.

No separate account or subscription is needed. Users authenticate with their existing Microsoft 365 identity.

Who uses it

Account managers, merchant success managers, and business operations teams who prepare recurring QBR readouts for merchants or partners.

Permissions requested and why

PermissionTypeWhy it's needed
identity Microsoft 365 standard Identifies the signed-in user to personalize responses
messageTeamMembers Microsoft 365 standard Allows the agent to send response cards within Teams conversations
Files.ReadWrite Microsoft Graph delegated Allows the app to search and read selected QBR data files in the signed-in user's OneDrive and, only after explicit confirmation, create or update generated QBR workspace artifacts there.
offline_access Microsoft identity delegated Keeps the user's delegated connection available without repeated sign-in prompts.

The app does not request access to email or calendars, does not request Files.ReadWrite.All, and does not use application-level Microsoft Graph permissions. File search and workspace saving are limited to the signed-in user's OneDrive.

Where data lives

  • Merchant data processing occurs in IntelliThing's Azure-hosted backend (Azure Functions and Azure Blob Storage).
  • CSV or TSV file content selected from OneDrive is read for scorecard generation. Raw customer file content is processed in memory and is not persisted by the backend.
  • Generated PowerPoint artifacts may be stored temporarily in Azure Blob Storage with time-limited download links.
  • When the user explicitly confirms OneDrive delivery, generated scorecards, batch indexes, ZIP bundles, and related workspace artifacts are written to the signed-in user's OneDrive.
  • Authentication is handled entirely by Microsoft Entra ID (OAuth 2.0 delegated flow). IntelliThing never sees user passwords or raw tokens.

How to approve

When a user clicks Request approval on the app listing, the request appears in the M365 Admin Center.

Step 1: Sign in to admin.cloud.microsoft

Step 2: Navigate to either:

  • Agents → All agents → Requests (recommended for Copilot agents)
    https://admin.cloud.microsoft/#/agents/all/requested
  • Settings → Integrated apps → Requested apps (also works)
    https://admin.cloud.microsoft/#/Settings/IntegratedApps

Step 3: Find Merchant QBR AutoPilot by IntelliThing, Inc. and select Accept request.

Once approved, the app becomes available to the requesting user. You can also deploy it to a broader group from the same screen.

If no request is visible yet

Ask the user to open the Teams or Microsoft 365 Copilot app link above and click Request approval. You can also look it up from Microsoft Marketplace using the product name and then manage availability from your tenant's app and agent controls.
