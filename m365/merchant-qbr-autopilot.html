What It Does

Turns merchant exports into QBR-ready scorecards in one conversation

Instead of rebuilding the same review across every account, the agent accepts sample data, pasted CSV, or a selected CSV/TSV file in OneDrive and returns structured scorecards with executive summaries, recommended actions, PowerPoint outputs, and optional batch packaging.

  • Single-merchant or batch scorecard generation
  • Executive summaries, supporting insights, and recommended actions
  • PowerPoint scorecards ready for direct use in QBR meetings
  • OneDrive folders, index files, and ZIP bundles for batch runs

Sample starter data, no setup required

Start immediately using bundled sample merchants, or save an app-provided starter CSV to OneDrive and replace the rows with your own merchant data.

OneDrive CSV/TSV scorecards

Point the agent at a file in your OneDrive, preview the fields, then generate scorecards from real performance inputs. The agent validates the file and reports per-account issues clearly.

Presentation-ready outputs

Every scorecard generates a branded PowerPoint deck. Batch runs can also be saved to OneDrive with an index and ZIP bundle for easier review or sharing.

How It Works

A simple Copilot flow from data to QBR package

1. Choose sample or own data Ask for sample merchants, paste CSV data, or select a CSV/TSV file from OneDrive.
2. Select one merchant or a batch Name one merchant, several merchants, or ask for every merchant in the file.
3. Review per-account results The agent returns key metrics, executive summaries, recommended actions, and row-level status.
4. Save and share the package Save outputs to OneDrive, create a ZIP bundle, and open a draft Outlook email when ready.

Installation

Requires IT admin approval — takes minutes

Like all Microsoft 365 Copilot agents from third-party publishers, Merchant QBR AutoPilot requires approval from your IT admin before it can be added. This is standard M365 tenant policy.

Here's the fastest path:

  1. In Microsoft Teams or Microsoft 365 Copilot, open the app/agent store and search for Merchant QBR AutoPilot or merchant qbr, then click Get it now or Request approval.
  2. Forward the IT admin guide to your IT team.
  3. Your admin approves it at M365 Admin Center → Agents → All agents → Requests.

Permissions requested

  • User identity — to personalize responses
  • Message team members — to send response cards in Teams
  • Files.ReadWrite — selected OneDrive files and confirmed QBR workspace saves
  • Offline access — keeps the delegated connection available without repeated sign-in

No email or calendar permissions. No Files.ReadWrite.All. No application-level file permissions. OneDrive file access is delegated to the signed-in user.

FAQ

Common questions

Is this app free?

Yes. Merchant QBR AutoPilot is free to use. No subscription or purchase required.

Do I need a separate account?

No. Users authenticate with their existing Microsoft 365 work account. No sign-up required.

Can I use my own merchant data?

Yes. Paste CSV data in chat or select a CSV/TSV file from your OneDrive. Sample merchants and starter files are also available so you can see the expected format before using your own data.

Where is data processed and stored?

Processing happens in IntelliThing's Azure-hosted backend. Raw customer file content is processed in memory and is not persisted by the backend. Generated artifacts may be stored temporarily in Azure Blob Storage, and confirmed workspaces are saved to the signed-in user's OneDrive.

What Microsoft 365 plan do I need?

The app requires a Microsoft 365 plan that includes access to Microsoft 365 Copilot and Teams.
