Getting Started with Merchant QBR AutoPilot

Last updated: August 22, 2026 · Applies to: Merchant QBR AutoPilot v4.1

Find the app in Microsoft 365: Open Merchant QBR AutoPilot in Teams, search for Merchant QBR AutoPilot in Microsoft Marketplace, or open the app directly in Microsoft 365 Copilot. If your tenant requires approval, click Request approval and send the IT admin guide to your Microsoft 365 administrator.
Merchant QBR AutoPilot

1. Find and Open the Agent

In Microsoft Teams or Microsoft 365 Copilot, search for Merchant QBR AutoPilot. Add the app if it is available, or click Request approval if your organization requires IT admin approval.

2. Choose Sample, Starter, or Own Data

Ask for sample merchants, save the app-provided starter CSV to OneDrive, paste CSV data in chat, or point the agent at a CSV/TSV file in your OneDrive.

3. Choose One Merchant or a Batch

Generate a scorecard for one merchant, several merchants, or every merchant in the file. Batch generation supports up to 10 merchant accounts per request; larger sets are split into groups.

4. Generate and Review Scorecards

Confirm generation when prompted. The agent returns PowerPoint scorecards, per-account status, and validation details for any row that needs attention.

5. Save, Download, or Share

For OneDrive batches, save outputs to an organized workspace, create a ZIP bundle, and open a draft Outlook email with the ZIP link included. Temporary download links should be used before they expire.
